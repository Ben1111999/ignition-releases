# IgnitionAIO releases

Official Windows installers and update metadata are distributed through this repository’s Releases page. Application source remains private.

No customer installer has been published yet. The customer beta is undergoing build verification and signing setup. Do not treat development previews as signed releases.

When a release is published, download only its versioned IgnitionAIO installer. In-app updates use the same official release channel. Never upload profiles, payment information, proxy credentials, webhook URLs or account/session files to issues.
